# Medusa + Mercur capability matrix — AgeStyles F1

**Evidence date:** 2026-11-17 (UTC)
**Versions in the isolated lab:** Mercur 2.4.1, Medusa 2.22.3, PostgreSQL 17, Redis 7
**Decision scope:** whether to continue the isolated prototype. This matrix is not production approval.

| Requirement | Native behavior / evidence | AgeStyles action | State |
|---|---|---|---|
| Seller accounts and owner with multiple stores | One owner account can list/select two seller accounts; four seller stores are present across the two seeded owners. Own-store selection succeeds; another owner's store returns 403. | Add an explicit `Organization` domain/module only if consolidated legal/business data is needed beyond seller membership. Do not call seller membership an organization. | Verified baseline; explicit organization model pending. |

A2/B2 each had 20 available units at the matching location during inspection. | Do not use this field to disable buyer choices. ## Interim F1 decision

**Continue the isolated prototype** for web, mobile and the AgeStyles extensions listed above. **Do not approve production migration or cutover.** F1 remains open: the composite quote verifier has a reversible A2 price probe, but it requires an EUR seller region and also exercises order creation, stock and expiry; no isolated price-only run has passed. The explicit organization boundary and capability gaps need owner review, buyer/merchant switching needs UI validation, and tracking is absent from the deployed API image. Confirm the independent order count and record the final quote-first/owner decision. F0 backup/restore and VPS capacity gates remain separate blockers for migration and heavy deployment.

## Evidence and operating rules

- Seller role matrices: `apps/commerce-api/scripts/verify-seller-roles.mjs` and `apps/commerce-api/scripts/verify-kickz-store-roles.mjs`.
- Four-store owner/member isolation: `tools/scripts/verify-multistore-memberships.mjs`.
- Mixed cart: `apps/commerce-api/scripts/verify-multistore-checkout.mjs`.
- Dual actor: `apps/commerce-api/scripts/verify-dual-actor-identity.mjs`.
- Keep AgeStyles behavior in owned packages, modules, workflows, hooks, routes, or providers. Do not patch Medusa/Mercur package source; follow repository `AGENTS.md` and ADR-001.
- Lab evidence is isolated; it does not authorize production DNS, Supabase changes, migration, or public sales.
